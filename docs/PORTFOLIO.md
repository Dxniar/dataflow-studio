## Title

DataFlow Studio — Excel & CSV Automation with Python

## Description

DataFlow Studio is an AI-assisted personal portfolio project for repeatable Excel and CSV workflows. It addresses a common problem: customer tables arriving with duplicates, missing values, inconsistent text and incompatible layouts.

The application combines a Python processing engine with a desktop interface and a command-line tool. Users can select cleaning steps, preview original and processed data, merge compatible files, convert formats and reuse a JSON workflow across a batch. Exports protect source files, and each run reports its actual changes.

The demonstration uses synthetic customer records, including English, Russian and Kazakh text. It is not a paid client case study. Source code, automated tests, reproducible examples and usage documentation are included so the behavior can be inspected and reproduced.

## Technologies

Python · pandas · openpyxl · CustomTkinter · Typer · pytest · Ruff · GitHub Actions
