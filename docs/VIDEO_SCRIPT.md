## OBS recording instructions

1. Open the app at a readable size and load only the synthetic fixtures.
2. Add Window Capture for DataFlow Studio. Do not use full-display capture.
3. Set canvas/output to 1920×1080 or 1280×720, 30 fps. Fit the full app window without stretching it.
4. Record MKV for crash resilience, then use OBS File → Remux Recordings to export MP4.
5. Follow the table above; omit waiting time only with a visible edit, never fake operation success.
6. Add the captions in a video editor. Keep them outside the preview table and disclose any held still frames as an edited walkthrough.
7. Play the entire MP4 and confirm that paths and captions reveal no private material.

An edited walkthrough made from captured application screens is a screen-based demo, not an uninterrupted screen recording. Label it accordingly in the accompanying portfolio description.
